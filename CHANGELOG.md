# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 - 2026-08-19

Initial public release.

- Send and receive faxes through a reusable household line.
- Use SignalWire in production, Sinch as an optional adapter, or the no-charge demo provider.
- Assemble cover sheets and documents in the browser before transmission.
- Archive faxes and provider diagnostics in private Cloudflare storage.
- Send near-real-time email confirmations for received and delivered faxes.
- Manage number renewal, scheduled release, provider holds, and recovery from the web app.
- Deploy privately with Cloudflare Access, Workers, D1, R2, Workflows, Cron, and Email Service.
